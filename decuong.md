# ĐỀ CƯƠNG DỰ ÁN

## WEBSITE THƯƠNG MẠI ĐIỆN TỬ BÁN SÁCH

### 1. Thông tin đề tài

- **Tên đề tài:** Xây dựng website thương mại điện tử bán sách.
- **Loại dự án:** Website thương mại điện tử.
- **Mô tả:** Xây dựng website cho phép khách hàng xem sách, tìm kiếm sản phẩm, quản lý giỏ hàng và đặt mua sách với phương thức thanh toán khi nhận hàng (COD).
- **Mục tiêu:** Xây dựng hệ thống bán sách trực tuyến có giao diện dễ sử dụng, hỗ trợ quản lý sản phẩm và đơn hàng hiệu quả.

### 2. Công nghệ sử dụng

| Thành phần         | Công nghệ          |
| ------------------ | ------------------ |
| Frontend           | React              |
| Backend            | Laravel            |
| Database           | MySQL              |
| Giao tiếp          | RESTful API / JSON |
| Quản lý mã nguồn   | Git / GitHub       |
| Quản lý tiến độ    | Trello             |
| Thiết kế giao diện | Figma              |
